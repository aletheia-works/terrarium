terrarium runs aube, pitchfork and Biome locally in your browser through
formicarium. Commands and project files stay inside the browser session.

Use the [demo collection](/terrarium/demos/) to try a tool, or embed the
same terminal in your own page. Use [Vivarium](https://github.com/aletheia-works/vivarium)
to explain a bug and compare builds.
